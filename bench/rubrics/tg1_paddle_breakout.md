# rubrics: tg1_paddle_breakout

盲评 judge 读到以下维度与锚点，给 0-5 分。score 0 = 不可玩；3 = 达到需求；5 = 优秀。

## render_polish (权重 0.5)
描述：用 three.js 渲染 3D 游戏场景，有基本光照、配色一致、贴图/材质合理。
锚点：
- 0：没有 3D 渲染、白屏、或不可见
- 3：场景存在、球/拍/砖块是 3D 体元、可见
- 5：材质/光照/相机角度/阴影有质感，像真正的 3D 游戏

## input_feel (权重 0.5)
描述：输入响应（键盘/鼠标）即时，球拍/球手感真实，暂停/开始反馈清晰。
锚点：
- 0：没有输入响应、或操作带明显延迟
- 3：键盘控制可用，交互顺畅
- 5：手感优秀，带粒子/音效/相机震动等细节
