momozi-3A-GamegenBench 是一个「能玩、能看、能懂」的 3A 游戏生成评测台。 每个 AI 造出来的游戏可以直接在浏览器里玩，每一轮修改都有回放，每个分数都有据可查。

How it works

一个 Agent 的一生：造 → 改 → 优

真实游戏开发不是一次性写完。我们让 agent 连续工作好几轮，考验它「能不能守住已经做好的东西」。

STAGE 01

🎮 GameGen · 造出来

给一段游戏设想，agent 从零写出可玩的 3D 游戏。测的是「能不能真造出来」。

v0.1 已支持
STAGE 02

🔧 GameFix · 守住它

给一个「修改需求」，agent 去改自己上一版的代码。测的是「改完老玩法还灵不灵」。

roadmap v0.3
STAGE 03

✨ GameOpt · 做得更好

给出具体优化目标（手感/平衡/美术/音效），测它能不能逐项逼近目标。

roadmap v1.0
